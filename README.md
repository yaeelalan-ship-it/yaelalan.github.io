# 📊 يئيل علان | محلل بيانات وخبير Odoo

## 👋 نبذة سريعة

مرحباً! أنا **يئيل علان**، محلل بيانات متخصص في تنفيذ أنظمة Odoo، وحاصل على ماجستير في علوم الويب (MWS).

أعمل على تحويل البيانات التشغيلية المعقدة إلى رؤى واضحة تدعم اتخاذ القرار في الشركات، خاصة في مجالات:
- 📈 تحليل المبيعات والمخزون
- 🤖 أتمتة العمليات والتقارير
- 📊 بناء لوحات المعلومات التفاعلية
